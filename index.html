01

やりたいこと — プロジェクトゴール目標 — 專案目的

最終目標最終目標

LINEで商品紹介を受けた顧客が、ランディングページ上でどの商品に興味を持ち詳細を見たかという行動データ（商品クリック）を、LINE IDと紐付けてSuper8 CRMにタグとして蓄積する。それを元に個人化された次のアクション（フォローアップ配信など）につなげる。 讓透過 LINE 收到商品介紹的顧客，在到達頁上點擊感興趣商品的行為資料（商品點擊），與 LINE ID 綁定並以標籤形式儲存至 Super8 CRM。以此為基礎，進行個人化的後續行動（如追蹤發送訊息）。

Q1

タグ付与用 Open API の存在確認確認標籤賦予用 Open API 是否存在

外部サイトからLINE IDを指定してタグを付与・更新できるAPIエンドポイントが提供されているか。エンドポイントURL・HTTPメソッド・必要パラメータ・認証方式を確認する。是否提供可從外部網站指定 LINE ID 進行標籤賦予/更新的 API 端點。確認端點 URL、HTTP 方法、必要參數及驗證方式。

「顧客のLINE IDに対してタグを付与するOpen APIのエンドポイントとパラメータ仕様を教えてください。SHOPLINEサイト上の商品クリックをトリガーにタグを自動付与したいです。」「請告知對顧客 LINE ID 賦予標籤的 Open API 端點與參數規格。我們希望以 SHOPLINE 網站上的商品點擊為觸發條件，自動賦予標籤。」
Q2

SHOPLINE会員ID ↔ LINE IDの紐付け方法SHOPLINE 會員 ID ↔ LINE ID 的綁定方式

SHOPLINEにログインした状態のユーザーのLINE IDを取得し、Super8のCRM上の顧客レコードと紐付けるための推奨手順を確認する。確認取得已登入 SHOPLINE 之用戶的 LINE ID，並與 Super8 CRM 上的顧客記錄綁定的推薦步驟。

「SHOPLINE会員のIDとLINE IDを紐付けた上で、行動タグをLINE ID単位でSuper8に記録することは可能ですか？推奨の実装方法を教えてください。」「將 SHOPLINE 會員 ID 與 LINE ID 綁定後，是否可以 LINE ID 為單位在 Super8 記錄行為標籤？請告知推薦的實作方式。」
Q3

SHOPLINE連携で取得できるデータの範囲確認確認 SHOPLINE 串接可取得的資料範圍

現在のSHOPLINE公式連携で、購入完了以外（商品閲覧・クリック等の行動データ）も取得できるかを確認する。確認目前 SHOPLINE 官方串接是否能取得購買完成以外的資料（商品瀏覽、點擊等行為資料）。

「SHOPLINE連携で取得できるデータ範囲を教えてください。購入データ以外に、商品クリックや詳細ページ閲覧などの行動データも取得できますか？」「請告知透過 SHOPLINE 串接可取得的資料範圍。除購買資料外，是否也能取得商品點擊或詳細頁瀏覽等行為資料？」
Q4

APIキーの取得方法・権限設定API 金鑰取得方式與權限設定

Super8の管理画面上でAPIキーを発行する手順、および外部からのAPI呼び出しに必要な権限の設定方法を確認する。確認在 Super8 管理介面發行 API 金鑰的步驟，以及從外部呼叫 API 所需的權限設定方式。

「外部サイトからAPIを呼び出すためのAPIキーの発行手順と、設定が必要な権限の範囲を教えてください。」「請告知從外部網站呼叫 API 所需的 API 金鑰發行步驟，以及需要設定的權限範圍。」
Q5

SHOPLINEサイトにGTMを導入してSuper8 APIへのタグ送信を行う構成がサポートされているか、またはドキュメント・サンプルコードが提供されているかを確認する。確認透過在 SHOPLINE 網站導入 GTM 並傳送標籤至 Super8 API 的架構是否受到支援，或是否提供相關文件與範例程式碼。
